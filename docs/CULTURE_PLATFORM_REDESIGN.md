# Culture in Motion: platform layout redesign

The second design study now extends beyond a palette change. This is a review-only redesign, opened at `/design-lab/culture`, with the existing destinations at `?look=culture`. It is not the default site and has not been deployed.

Each destination opens with a numbered editorial chapter: large type, an animated tilted photographic collage, a lime stamp, a clear introduction and a jump directly to the existing workspace. Motion can be paused and respects reduced-motion preferences.

Marketplace uses an offset record-sleeve catalogue. INDEX uses a ruled editorial chart and tilted insight cards. Artist and distribution workspaces use a dark tab rail, large typographic metrics, open ruled sections and pink callouts. Brand discovery uses larger tilted artist imagery. SONIC NOW has a new two-part listening console. Venue discovery and audience prediction inherit the same editorial system. FACTS SHOW uses an oversized photographic episode spread. Track detail uses a tilted sleeve, enlarged title and a distinct pale-lime purchase column.

Original page functionality and role gates are reused. All established destinations remain accessible. Navigation carries the review style between pages; Home returns to the matching landing study. Financial logic, artist data and the independent prototype are untouched. Simulated integrations remain identified.

Actual desktop, mobile, full-page screenshots and a motion walkthrough accompany this review. The default Electric candy presentation remains available outside this explicit study.

Validation: lint, TypeScript, production build and all 18 domain tests passed. All 23 existing journey/Marketplace browser checks passed. The four new redesign checks passed after repairing text contrast on pink panels: nine page layouts at desktop/mobile widths, role-aware navigation/sample identification, and animated artwork pause/reduced-motion behavior. The final landing-link change was checked again against the completed build.
